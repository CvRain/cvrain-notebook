# 842 信息化概论 · 单元练习册（总入口）

> 依据 2027《信息化概论》考试大纲 +《信息系统导论》教材（黄正洪、赵志华《信息技术导论》，人民邮电 2017）+ 2021–2024 历年真题风格自编，**非官方试题**。

## 一、为什么做这套练习册

842 整卷是「名词解释 30 + 简答 60 + 论述 60」。直接刷整卷，等于每次都在**考场默写**，复习很累、反馈也慢：错一个概念，你分不清是"没记住关键词"还是"两个概念混了"。

所以这套练习册把学习拆成三层：

| 层次 | 对应板块 | 解决什么 |
| --- | --- | --- |
| 记忆层 | **必背术语速查**（每条一句话＋必须出现的关键词） | 知道意思但写不出得分词 |
| 理解层 | **术语辨析表**＋判断题（须写改正）＋配对/情景题 | 近义概念混淆 |
| 输出层 | 简答＋综合/论述（带答题留白） | 会认不会写、写不出结构 |

每套 100 分、约 60–75 分钟，做完对答案，错题回查教材原文。

## 二、使用顺序建议

1. **按单元顺序做**（01 → 09），每个单元先看「知识地图」再看题，不要一上来就做。
2. 每套限时 60–75 分钟，**判断题一定要写出改正**，否则等于没做。
3. 对答案时重点看「解析」里的**教材节号/页码**，错题回翻原书对应段落。
4. 一个单元做完隔 3–5 天，**只重做错题**，不重做整卷。
5. 全部单元过完后，再做 [整卷模拟卷](../842信息化概论-模拟卷/) 检验。

## 四、每套的固定结构

1. **知识地图**：本单元术语的层级/因果链，3–6 行
2. **必背术语速查**：8–14 条，每条「**术语**：一句话核心（含关键词）」
3. **术语辨析**：2–4 组近义概念对比表
4. **客观题（约 60 分）**：单选、多选（正确项 ≥2）、判断题（须写改正）、配对/填空
5. **简答题（约 24 分）**：3–4 题，带答题留白
6. **综合/论述题（约 12–16 分）**：1 题，结合农业或信息化实践

## 五、单元划分依据

为什么是这 9 个单元、而不是教材的 11 章：见 [单元划分方案.md](单元划分方案.md)。
要点：按考试权重切分；教材第 10、11 章（自动化与智能控制、智能家居与智能汽车）历年几乎不考，压缩为其他单元的辨析素材；农业应用板块教材几乎没有，单独成第 09 单元。
