## 六、教材依赖与发现的问题

1. **教材题名**：课程材料封面为《信息系统导论》，版权页实为黄正洪、赵志华主编《信息技术导论》
   （ISBN 978-7-115-42628-4，2017 年 1 月）。本练习册以该教材第 3 章 3.2 节原文为准。
2. **数据库原理条目教材未展开**：教材 3.2 节只讲数据、文件到数据库、三种传统数据模型、关系数据库产品、
   SQL、结构化／非结构化数据；大纲「数据管理的发展过程、数据库原理与基本概念」所要求的
   **数据管理四阶段、DBMS／DBS、数据模型三要素、E-R 模型、三级模式两级映像、键、三类完整性、视图、
   事务 ACID** 在教材中均无专节展开。本册依大纲并参照通行数据库理论（王珊《数据库系统概论》口径）补充，
   答案解析中统一标注「大纲补充／通行数据库理论」，不冒充教材原文。
3. **信息系统组成教材无专节**：大纲「一、信息技术」第 3 条要求掌握“信息系统组成”，但教材没有信息系统专章
   （第 1 章只讲信息技术与信息社会，第 8 章讲电子政务）。本册练习二按通行信息系统理论编写：
   组成要素为人、硬件、软件、数据、处理规程，基本功能为输入、处理、输出、存储、控制，
   类型为 TPS／MIS／DSS；答案中均已注明“通行信息系统理论、大纲要求”，不标注教材页码。
4. **关系数据库产品仅作背景**：教材 3.2.3 列举 FoxPro、SQL Server、Oracle、DB2、MySQL 五种产品，
   其中 FoxPro 已基本淘汰。本册只把产品系列作为背景知识（见知识地图与术语表），未就产品版本细节命题，
   避免把复习引向死记产品参数。
5. **SQL 标准年份**：教材 3.2.4 称 1986 年 10 月美国国家标准协会（ANSI）对 SQL 进行规范，
   1987 年成为国际标准；本册未就具体标准编号命题，避免 OCR 噪声（教材原文编号识别为“ANSLX3.135-1986”）。
6. **视图与事务的归属**：这两项在 842 真题中可能以名词解释或简答出现，本册放在练习一覆盖；
   教材 3.2 节未讲视图和事务，故答案注明属大纲补充。
7. **OCR 噪声**：教材为扫描 OCR，“冗余度”被识别为“元余度”、“嵌套”被识别为“骨套”等，
   本册按上下文与通行术语校订，并用页脚数字校验页码。
8. **真题对应**：2022 年名词解释「数据库」对应练习一单选 2 与简答 1；341 数据库真题「视图及优点」
   对应练习一简答 3；「数据库的恢复方法」「并发控制带来的不一致性问题」在练习一事务、练习二数据备份与
   安全部分涉及，但未按 341 试卷的 150 分口径展开，以 842 单元练习的 100 分规模为准。
