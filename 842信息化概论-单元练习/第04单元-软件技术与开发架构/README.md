## 六、教材依赖与发现的问题

1. **B/S、C/S 架构与 Web 服务教材未覆盖（重要）**：经对教材 OCR 全文检索确认，教材第 3 章 3.3 节
   只讲软件工程、软件过程（瀑布模型）与软件项目管理，**没有** B/S、C/S 架构与 Web 服务的专节；
   全书仅有零星线索（3.2 讲 DB2 提到“客户机/服务器用户”、6.3.1 列出 HTTP、4.1.1 提到亚马逊的
   Web Service）。因此练习二的架构与 Web 服务部分**按 2027 年考试大纲“二、计算机与软件技术”第 3、4 条
   与通用规范知识命题**，属“教材未覆盖，按大纲补充”；答案册在对应题目逐条注明，并对“服务三要素、
   三种角色、三层架构、HTTP 请求—响应”给出规范表述，供背诵使用。
2. **教材页码换算**：OCR 扫描页与印刷页相差 7 页，本册标注的页码已用页脚数字交叉校验（如扫描页
   0129 页脚为 122）。个别页脚被 OCR 识别为噪声（如 `-99`），不影响节次定位。
3. **软件开发三阶段年份**：教材 3.3.1 将第二阶段记为 1960—1970 年（软件设计阶段），与个别资料
   “1950—1970”不同，本册从教材。
4. **CMM 译名与缩写**：教材写作 CMM（Capability Maturity Model for Software，SW-CMM），
   并指出“在具体管理上过于繁琐和复杂，且近年有弱化的趋势”；本册判断第 6 题据此设计，答题时
   既肯定优化级为最高等级，也可补充该局限，体现辩证性。
5. **“软件开发流程”真题口径**：2022、2023 年真题简答“软件的开发流程”可用教材瀑布模型的
   6 个基本活动回答（需求分析→架构设计→详细设计→编码→测试→维护），本册练习一简答 3 与
   练习二综合均按此口径组织，并提示“若需求多变则不宜硬套瀑布模型”。
6. **Web 服务与 SOA 的教材缺口**：教材未定义 SOA，大纲要求“Web 服务及其体系架构”，本册按通用
   规范知识补充 SOA、SOAP、WSDL、UDDI 与三角色，并说明 Web 服务是 SOA 的主要实现技术之一。
7. **OCR 噪声**：教材为扫描 OCR，个别词存在噪声（如“瀑布模型”被识别为“溪布模型”、“高晶”应为
   “高昂”），本册按上下文与通行表述写作“瀑布模型”“高昂”，不影响答案事实。
