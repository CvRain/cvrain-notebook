## 三、扫描教材转文本（OCR）

四本参考书都是**扫描件，无文字层**，已用 tesseract（chi_sim，语言包放在项目内 `tmp/ocr_out/tessdata/`，不动系统目录）逐页识别：

| 教材 | 页数 | 文本 |
| --- | --- | --- |
| 信息系统导论（黄正洪《信息技术导论》2017） | 236 | `tmp/ocr_out/信息系统导论/book.txt` |
| 计算机网络（第 8 版，谢希仁） | 485 | `tmp/ocr_out/计算机网络（第8版）/book.txt` |
| C 语言程序设计（第五版，谭浩强） | 395 | `tmp/ocr_out/C语言程序设计（第五版） -- 谭浩强 -- 计算机/book.txt` |
| 谭浩强《C 程序设计》学习辅导（第五版） | 307 | `tmp/ocr_out/谭浩强《C程序设计》学习辅导（第五版）/book.txt` |

- 合计 **1423 页、约 166 万字符**，正文识别质量可用（中文段落干净），**代码段不可靠**（如 `%5.2f` 会被识别成 `%%5. 2f`），查代码请回看原 PDF。
- 每本书另有：`pages/NNNN.txt`（逐页文本，便于定位）、`meta.json`（页数/耗时/参数）。
- 流水线脚本：`tmp/ocr_out/ocr_books.py`（支持 `--only`、`--resume` 断点续跑、`--jobs` 并发）。
  重跑示例：`python3 tmp/ocr_out/ocr_books.py --jobs 8 --only 信息系统导论 --resume`
- 历年真题已转文本：`tmp/ocr_out/_真题/`（脚本 `extract_exams.py`，doc/docx→pandoc/soffice，pdf→pdftotext，jpg→OCR）。
- 输出全部在 `tmp/` 下，已在 `.gitignore` 中排除，不污染仓库。

## 四、重新编译试卷

```bash
./build-exams.sh                      # 编译全部（已有且比源文件新则跳过）
./build-exams.sh --force --tex 数据库   # 只强制重编文件名含「数据库」的
python3 exam-template/check_scores.py  # 校验各卷分值是否恰好等于封面满分
```

- 样式：`exam-template/exam-style.sty`（通用）＋ `exam-style-341.sty` / `exam-style-842.sty`（分科）。
- 编译必须从**仓库根目录**执行 `xelatex`，脚本已自动设置 `TEXINPUTS`。
- 产物：各目录下 `out/<文件名>/`（中间文件）与同名 `.pdf`。

## 五、备考建议（按现有材料的用法）

1. **先做整卷**：341 三科各 50 分可单独计时 60 分钟；842 按 180 分钟整卷做。
2. **对答案看给分点**：答案里的「解析」标注了得分点与常见失分，比答案本身更值钱。
3. **回教材查证**：用 `tmp/ocr_out/<书名>/pages/NNNN.txt` 或 `book.txt` 全文检索定位到原书页码后，再翻开 PDF 看原始排版（尤其公式与代码）。
