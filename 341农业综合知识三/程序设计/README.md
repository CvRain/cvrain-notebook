## 五、答案位置与说明

- 参考答案与试卷同目录、同名（`answers-XX`）。
- 单项选择题均给出关键解析；填空题给出答案与理由；程序阅读题给出逐步推演；编程题给出**完整可编译**的参考实现、评分要点与易错点。
- 全部程序阅读题的结果与编程题参考实现均已用 `gcc -std=c99 -Wall` 实际编译运行核对；选择题中可运行的代码片段同样经过编译运行验证。

## 六、编译方法

在仓库根目录执行：

```bash
./build-exams.sh --force --tex 程序设计
```

或对单个文件执行两次 xelatex（第二遍解析 `LastPage` 页码引用）：

```bash
TEXINPUTS=".:./exam-template:" xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory="341农业综合知识三/程序设计/out/mock-exam-01" \
  "341农业综合知识三/程序设计/mock-exam-01.tex"
```

编译成功后 `build-exams.sh` 会把 PDF 复制到本目录。

> 说明：`exam-template/exam-style-341.sty` 中额外关闭了代码字体的编程连字（`Ligatures=NoCommon`、`RawFeature={-calt}`）。
> 否则 CaskaydiaCove NF 会把 `<=`、`>=`、`!=`、`->` 渲染成 `≤`、`≥`、`≠`、`→` 等单个符号，并使行内 `\code{}` 中 `==`
> 的文本提取结果出错（复制或检索时变成 `=)`）。关闭后 C 运算符在试卷与答案中原样显示。
