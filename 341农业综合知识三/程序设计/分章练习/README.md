## 三、每套练习的固定结构

每套练习均包含以下 7 个板块（与 842 单元练习册同构，内容换成 C 语言）：

1. **知识地图（knowmap）**：3–6 行，梳理本章知识结构与主线。
2. **必背要点速查（keyterms）**：8–14 条「**要点**：一句话」，含必须记住的语法细节与易错点。
3. **易混点辨析（contrast）**：2–4 组对照表，行用 `\citem{概念}{要点A}{要点B}{要点C}` 四参数。
4. **客观题约 65 分**：单选、多选（≥2 正确项）、判断（含改正）、填空、程序阅读写结果。
5. **简答 2–3 题**。
6. **综合题 1 题**：编程题或程序填空题，答案给**完整可编译参考实现**及运行结果。
7. 答案册逐题解析：选择题说明正确项依据与干扰项错因，判断题给出改正后的表述，程序题给出 gcc 实跑结果。
