- 每套试卷的参考答案放在对应的 `answers-0X.pdf` 中，按试卷题号顺序（1～19）逐一给出。

## 五、编译方法

在仓库根目录执行（`exam-style-341.sty` 位于 `exam-template/`，靠 `TEXINPUTS` 找到）：

```bash
./build-exams.sh --tex 数据库          # 编译本目录 4 个 tex，每个两遍 xelatex
./build-exams.sh --tex 数据库 --force  # 忽略时间戳强制重编
```

或逐个编译：

```bash
TEXINPUTS=".:./exam-template:" xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory="341农业综合知识三/数据库/out/mock-exam-01" \
  "341农业综合知识三/数据库/mock-exam-01.tex"
```

中间产物（`.aux`、`.log`、`.pdf`）在 `out/<文件名>/` 下，编译成功后脚本会把 PDF 复制回本目录。
