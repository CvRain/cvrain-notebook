## 二、每套练习的固定结构

| 板块 | 内容 | 说明 |
| --- | --- | --- |
| 知识地图 | 3～6 行 | 用“概念链→层次→要点”的方式串起本章框架 |
| 必背术语速查 | 12～14 条 | 每条为“**概念**：一句话定义（含关键限定）” |
| 术语辨析 | 3～4 组 | 易混概念对照，如主码/候选码/外码、1NF/2NF/3NF/BCNF、三级封锁协议 |
| 一、单项选择题 | 10 题 × 2 分 = 20 分 | 覆盖本章基本概念与简单推理 |
| 二、多项选择题 | 5 题 × 4 分 = 20 分 | 每题至少 2 个正确项，错选/漏选不得分 |
| 三、判断题 | 5 题 × 2 分 = 10 分 | 判断后要求写出改正后的表述 |
| 四、填空题 | 5 题 × 2 分 = 10 分 | 概念、符号、闭包、协议要点 |
| 五、简答题 | 2 题 × 8 分 = 16 分 | 给出答题要点与评分点 |
| 六、综合题 | 2 题 × 12 分 = 24 分 | SQL / E-R / 规范化 / 并发与恢复，按步骤给分 |
| **合计** | **29 题** | **100 分，建议 60 分钟** |

各套分值均精确加总为 100 分（客观题 60 分，简答 16 分，综合 24 分），可由 `exam-template/check_scores.py` 自动校验。

## 四、答案位置与解析标准

- 每套练习的参考答案放在对应的 `答案-0X-*.pdf` 中，按练习册题号顺序（1～29）逐一给出。
- 单项选择题、多项选择题、判断题、填空题**每题均有解析**；判断题另给出改正后的正确表述。
- 简答题给出“参考答案要点”和评分要点；综合题按小问给出完整步骤：
  - SQL 题按 **MySQL 语法**书写（复合主码用表级 `PRIMARY KEY`、外码用 `FOREIGN KEY ... REFERENCES`、组函数只能出现在 `HAVING` 中），并说明易错点；
  - 规范化题完整给出闭包运算、候选码推导、范式判定理由、最小依赖集、分解过程、无损连接性验证（二元分解定理）与保持函数依赖说明；
  - E-R 题给出联系类型判断、转换规则与全部关系模式（主码、外码）；
  - 并发与恢复题给出逐条日志推演、UNDO/REDO 集合与恢复后的数据值。
- 答案中不含“略”“略述”等省略写法，所有计算过程均写出中间步骤。

## 六、编译方法

在仓库根目录执行（`exam-style-341.sty` 位于 `exam-template/`，靠 `TEXINPUTS` 找到）：

```bash
./build-exams.sh --force --tex 数据库/分章练习   # 编译本目录 10 个 tex，每个两遍 xelatex
python3 exam-template/check_scores.py 分章练习   # 校验各套分值是否精确加总为 100 分
```

中间产物（`.aux`、`.log`、`.pdf`）在 `out/<文件名>/` 下，编译成功后脚本会把 PDF 复制回本目录。

## 七、使用建议

1. 先看每套开头的「知识地图」和「必背术语速查」建立本章框架，再独立完成客观题；
2. 对答案时重点看解析中的“易错点”，判断题务必核对改正后的表述；
3. 简答题按“要点 + 展开”作答，综合题按小问逐步书写，规范化题不能只写结论、必须写出闭包与验证过程；
4. 五章练习完成后，用 `../mock-exam-01.pdf`、`../mock-exam-02.pdf` 进行限时整卷模拟。
