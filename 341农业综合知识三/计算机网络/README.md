## 计算题答案速查（可复算）

| 试卷 | 计算题 | 关键结果 |
| --- | --- | --- |
| 一 | B 类地址 168.195.0.0 划分为 27 个子网 | 借 5 位（\(2^4<27\le 2^5\)）；掩码 255.255.248.0 = \(11111111.11111111.11111000.00000000\)；每子网 \(2^{11}-2=2046\) 台主机；第 1 个可用子网 168.195.8.0，可用地址 168.195.8.1～168.195.15.254 |
| 二 | 4000 字节 IP 数据报通过 MTU 1420 链路分片 | 每片最多 1420−20 = 1400 字节数据（片偏移以 8 字节为单位）；3980 = 1400+1400+1180，共 3 片；片偏移 0、1400/8 = 175、2800/8 = 350；MF = 1、1、0；总长度 = 1420、1420、1200 字节 |
| 二 | TCP 报文段序号 500、携带 200 字节 | 确认号 = 500 + 200 = 700（确认号表示期望收到的下一个字节序号） |
| 二 | CIDR 地址块 192.168.16.0/22 | 地址总数 \(2^{10}=1024\)，可分配主机数 \(1024-2=1022\) |

## 如何编译

在仓库根目录执行（共享样式在 `exam-template/`，教材与真题资料在 `tmp/`）：

```bash
# 方式一：只编译计算机网络部分的 4 个 tex（自动跑两遍并复制 PDF 回本目录）
./build-exams.sh --force --tex 计算机网络
#   --force 表示忽略时间戳强制重编；不加 --force 时，若 out/ 下的 PDF 已比 tex 新会直接跳过

# 只重编某一个文件
rm -f "341农业综合知识三/计算机网络/out/mock-exam-01/mock-exam-01.pdf"
./build-exams.sh --tex 计算机网络

# 方式二：手动编译单个文件（需跑两遍，第二遍用于回填页脚的「共 N 页」）
mkdir -p "341农业综合知识三/计算机网络/out/mock-exam-01"
TEXINPUTS=".:./exam-template:" xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory="341农业综合知识三/计算机网络/out/mock-exam-01" \
  "341农业综合知识三/计算机网络/mock-exam-01.tex"
```

编译结果：`out/<文件名>/<文件名>.pdf` 与复制到本目录的同名 PDF。四个文件均编译成功、
无 Overfull 警告、无未定义命令，PDF 与页脚页数一致（卷一 3 页、卷二 4 页）。

## 编写依据与说明

- 范围、章节与题型比例依据 2027 年《网络技术与应用》考试大纲。
- 真题风格参考 `tmp/ocr_out/_真题/` 中 2014、2018、2022、2023、2024 年 341 真题回忆版：
  选择题偏基础（PCM 量化与数据率、码元速率与调制、域名解析、A/B/C 类地址、光纤特点、
  模拟/数字信号转换、接收邮件协议），名词解释（基带信号、ARP、FTP、RTT、服务访问点、
  信号、MAC 地址、网络协议），简答（CSMA/CD、TCP 三次握手、域名服务器分类、
  网络安全威胁），大题（子网划分与子网掩码、IP 分片与片偏移、TCP 序号与确认号推算）。
- 术语、协议细节与公式均按谢希仁《计算机网络》第 8 版核对；CSMA/CD 与争用期、最短帧长
  的表述已与教材正文逐条比对（教材第 3 章「争用期 = 51.2 μs = 512 bit = 64 字节」）。
- **本目录内容为自编模拟题，不是官方试题，仅供复习自测使用。**

## 相关样式说明

本目录试卷使用 `exam-template/exam-style.sty`。该共享样式做了两处与编译环境有关的小修正
（不影响其他目录已编译好的试卷）：

1. `notestyle.sty` 的定位改为按 `./`、`../`、`../../`、`../../../` 依次探测，
   使固定命令 `TEXINPUTS=".:./exam-template:" xelatex ...` 从仓库根目录编译可用
   （新版 TeX Live 会忽略 `\input@path` 中以 `..` 开头的条目）；
2. 封面 `\examcover` 不再重置页码，使页脚「共 N 页」与 PDF 实际页数一致。
