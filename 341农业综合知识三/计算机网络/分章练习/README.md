## 二、各章知识点覆盖

### 第 01 章 计算机网络基本概念与性能指标
定义与两大功能（连通性、共享）；互联网基础结构发展三阶段；internet 与 Internet 的区别；
发展四阶段（大纲要求，教材以互联网三阶段为主，按大纲补充）；分类（按范围 WAN/MAN/LAN/PAN、按拓扑、按交换方式）；
电路交换、报文交换、分组交换；7 个性能指标（速率、带宽、吞吐量、时延、时延带宽积、RTT、利用率）；协议与分层初步。

### 第 02 章 协议与体系结构
分层思想；协议三要素（语法、语义、同步）；OSI 七层；TCP/IP 四层；五层原理体系结构；
各层功能、PDU（比特／帧／分组／报文段／报文）与典型设备；封装与解封装；
OSI 与 TCP/IP 的比较；客户／服务器方式与 P2P 方式；标准化组织与 RFC。

### 第 03 章 物理层
物理层任务与接口四特性（机械、电气、功能、过程）；数据通信系统模型；码元、波特率与比特率；
奈氏准则与香农公式；基带调制与带通调制（ASK/FSK/PSK/QAM）；PCM（采样定理、量化、编码）；
传输媒体（双绞线、同轴电缆、光纤、无线）；信道复用（FDM/TDM/STDM/WDM/CDMA）；交换方式。

### 第 04 章 数据链路层
链路与数据链路；三个基本问题（封装成帧、透明传输、差错检测）；字节填充与零比特填充；
CRC 循环冗余检验与 FCS；停止等待协议、连续 ARQ（回退 N 帧）、选择重传 ARQ、滑动窗口；
PPP 的三个组成部分、帧格式与工作状态。

### 第 05 章 局域网与广域网
IEEE 802 标准；以太网与 CSMA/CD；争用期 51.2 $\mu$s 与最短帧长 64 B；截断二进制指数退避；
MAC 地址与以太网帧格式；交换机自学习与 VLAN；高速以太网；无线局域网 802.11 与 CSMA/CA；
广域网与 PPP、HDLC、ATM、帧中继。

### 第 06 章 网络层
IP 数据报格式与首部字段；分类地址 A/B/C/D/E 与私有地址；子网划分（借位、掩码、子网地址/广播地址/可用主机数）；
CIDR 与路由聚合；IP 分片（MTU、片偏移单位 8 字节、MF/DF、总长度）；ARP、ICMP；路由选择协议 RIP/OSPF/BGP
（距离向量 vs 链路状态）；IPv6 与 NAT。计算题：C 类 /24 划 5 个子网（借 3 位、/27、30 台）、
4 个 C 类聚合为 /22、3020 B 过 MTU 1500 分 3 片（偏移 0/185/370）。

### 第 07 章 运输层
端口与套接字；UDP 特点与首部；TCP 特点、首部、三次握手与四次挥手、序号与确认号推算、超时重传；
流量控制（滑动窗口、`min(rwnd,cwnd)`）；拥塞控制（慢开始、拥塞避免、快重传、快恢复）。
计算题：ISN 与 seq/ack 推算、发送窗口、cwnd 变化序列与超时后的 ssthresh/cwnd。

### 第 08 章 应用层
DNS（域名结构、递归/迭代解析、域名服务器分类、MX 记录）；FTP（控制连接 21/数据连接 20、主动与被动）；
电子邮件（SMTP、POP3/IMAP、MIME）；WWW（HTTP 请求—响应、URL、Cookie）；DHCP。综合题：一封邮件的完整传送过程。

### 第 09 章 网络安全
安全威胁与攻击类型（被动/主动、篡改/伪造/重放/拒绝服务）；对称密钥体制（DES/AES）；
公开密钥体制（RSA、公钥加密私钥解密、私钥签名公钥验证）；数字签名与报文鉴别（Hash）；
SSL/TLS；防火墙与入侵检测。计算题：RSA 小素数算例（p=3,q=11,e=3 → d=7，加解密还原）。

## 八、教材依赖与发现的问题

1. **页码换算**：教材 OCR 从封面、目录开始扫描，`PAGE n` 对应印刷页 **11**。本册答案中的印刷页均已按此换算，
   并用章首页与页脚数字（如扫描页 162 页脚“155”）交叉校验。
2. **第 8 版删减了 ARQ 协议细节**：谢希仁第 8 版数据链路层只保留三个基本问题与 PPP，
   停止等待协议、连续 ARQ（回退 N 帧）、选择重传 ARQ 的详细内容已不在正文中；但 2027 大纲明确要求
   这四种可靠传输机制。本册按大纲与通用教材补充，答案中已逐处标注“教材第 8 版未展开，按通用教材补充”。
3. **广域网协议**：第 8 版正文未展开 HDLC、ATM、帧中继，仅保留 PPP；本册第 05 章的广域网部分
   以 PPP 为教材依据，HDLC／ATM／帧中继按大纲与通用教材补充并注明。
4. **PCM**：教材 2.5 只把 PCM 作为数字传输系统的标准简要提及，采样、量化、编码与数据率公式
   按通信原理通用教材补充；2022 年真题“128 量化级、8000 次/秒采样”的答法为 $8000\times\log_2 128=56$ kb/s。
5. **无线局域网不在第 3 章**：教材第 8 版把无线局域网放在第 9 章 9.1，本册按大纲“五、局域网”把 802.11 与
   CSMA/CA 并入第 05 章，答案标注教材 9.1（印刷页 405—419）。
6. **交换方式**：教材在 1.3.2 讲电路交换、报文交换和分组交换，属第 1 章内容；本册在第 01 章命题，
   第 03 章仅作“物理层与数据通信”的衔接，避免重复。
7. **341 大纲题型结构与分章练习结构不同**：大纲卷面为单选约 40%、填空约 20%、名词解释约 20%、简答约 20%，
   本册为分章复习保留判断、计算与综合题，正式考试题型以大纲为准；名词解释可在 keyterms 与简答题中覆盖。
