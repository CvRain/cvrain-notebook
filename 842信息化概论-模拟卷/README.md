## 四、编译方法

在仓库根目录执行（`exam-style-842.sty` 位于 `exam-template/`，通过 `TEXINPUTS` 引入）：

```bash
TEXINPUTS=".:./exam-template:" xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory="842信息化概论-模拟卷/out/mock-exam-01" \
  "842信息化概论-模拟卷/mock-exam-01.tex"
```

每个文件需编译两遍（第一遍解析 `lastpage` 的 `LastPage` 与交叉引用）。也可直接在仓库根目录运行：

```bash
./build-exams.sh --tex 信息化概论-模拟卷
```

## 五、答案说明

- 名词解释每题给出 3—5 个要点，按 5 分写足；简答题分点作答并标明分值分布。
- 论述题按“答题框架 + 关键得分点 + 结合农业/乡村振兴的分析思路”组织，包含破题立意、分点展开、对策与深化分析。
- 每题答案后以 `解析：` 标注得分点与常见失分处，便于对照自评。
- 卷面留白：名词解释每题 2.0 cm，简答题每题 3.2 cm，论述题每题 11—13 cm（≥ 6 cm）。

## 六、注意事项

- 本目录试卷**依据大纲与历年真题风格自编，非官方试题**，不代表学校公布的正式卷式与题量分布。
- 教材 OCR 文本存在识别噪声，凡教材专属定义、章节归属、术语均应按纸质教材复核；本卷题目以大纲与教材通行表述为准。
- **教材术语特别提示（已按教材原文调整）**：本教材第 7 章把物联网体系结构划为**四层**——感知层、网络层、**支撑层**、应用层，其中支撑层指“在高性能网络计算环境下把海量信息资源整合为可互联互通的大型智能网络”的云计算与海量存储超级平台。业界常用的三层划分（感知层/网络层/应用层）与之实质一致。因此卷二第 10 题问“通常划分为哪几层”，答案同时给出两种划分并说明对应关系，两种答法均给分。
- 本教材第 4 章明确采用 NIST 对云计算服务模式的权威划分（IaaS/PaaS/SaaS 三个层次），卷一对该题的答案与教材一致。
- 教材以物联网传感网口径表述“精准农业”（面向农田、园林、温室等目标区域的射频技术与无线传感器网络架构），本卷按大纲口径给出更通行的“按空间差异实施变量投入”定义，答题时两者可结合使用。
