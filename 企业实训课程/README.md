## 五、开卷命题思路

1. **减少纯记忆题**：选择题尽量给出小场景或小计算，避免“翻书即可照抄”的定义题。
2. **基础分与进阶分分层**：每套卷前 45 分（组成原理＋操作系统）以基础概念和简单计算为主；后 105 分（网络、数据库、信息导论）按考研选择题/综合题难度设计。
3. **强调过程与判断**：Cache 地址/平均访问时间、缺页次数、磁盘调度、TCP 拥塞窗口、IP 分片、VLSM、3NF 分解、索引设计均要求写过程或理由。
4. **SQL 与索引贴近工程**：既考标准 SQL 语义（`NOT EXISTS`、`>= ALL`、空值聚合、`GROUP BY/HAVING`），也考 B+ 树索引、回表与覆盖索引、最左前缀。
5. **材料分析跨章节整合**：智慧温室、校园一卡通、政务云、智能交通四个情境，把信息技术、计算机、软件、云/大数据、传感、网络、数据库串起来。

## 七、编译与校验

在仓库根目录执行：

```bash
./build-exams.sh --force 企业实训课程
python3 exam-template/check_scores.py 企业实训课程
```

也可以直接编译单套：

```bash
TEXINPUTS=".:./exam-template:./企业实训课程:$(pwd):" \
  xelatex -interaction=nonstopmode -halt-on-error \
  -output-directory="企业实训课程/out/midterm-01" \
  "企业实训课程/midterm-01.tex"
```

每个文件编译两遍，以解析 `lastpage` 的“共 N 页”。当前四套卷的 `check_scores.py` 校验结果均为 **150 分**。

## 八、命题依据与参考资料

- **信息系统导论（第 1—6 章）**：项目内 OCR 文本 `tmp/ocr_out/信息系统导论/book.txt` 与逐页文本，对应黄正洪、赵志华主编《信息技术导论》（人民邮电出版社，2017）第 1—6 章：信息技术与信息社会、计算机技术、软件技术、云计算与大数据、微电子与传感技术、通信与网络技术。
- **计算机网络**：谢希仁《计算机网络》（第 8 版）OCR 文本与项目内 341 网络分章练习、模拟卷。
- **数据库**：项目内 341 数据库模拟卷、分章练习中的 SQL、规范化、索引与事务题。
- **计算机组成原理、操作系统**：按本科通行的组成原理/操作系统教材与 408 基础题型自编；项目内暂无对应教材 OCR，题目控制在期末基础难度。
- **信息化概论**：项目内 842 模拟卷、单元练习与考试大纲，用于对齐“信息化、云计算、大数据、传感器、软件过程”等术语口径。

## 九、使用建议

1. **先做 A 卷**：熟悉五板块结构和答题节奏；A 卷答案中的评分点最详细，可作为讲评模板。
2. **B/C/D 轮换练习**：B 偏“协议与并发”、C 偏“计算与故障排查”、D 偏“综合设计与隔离级别”，可按复习进度选用。
3. **限时训练**：建议 180 分钟整卷计时；若只做单科，可按分值比例折算时间（如网络 35 分约 42 分钟）。
4. **附页使用**：试题已留简答/计算空白；写字较大的学生可使用卷末附页，作答时注明题号。
